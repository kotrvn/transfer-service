## Проверки

Установите Go версии, указанной в `go.mod`, Make и компилятор C для детектора гонок. Выполните `make check` в корне репозитория. Команда проверяет форматирование, запускает `go vet`, собирает пакеты и запускает тесты с детектором гонок. Тесты не требуют PostgreSQL.

Проверки можно запустить по отдельности через `make fmt-check`, `make vet`, `make build` и `make test`. Отчёт о покрытии сохраняется в `coverage.txt`. GitHub Actions запускает тот же `make check`.

## Локальный запуск API

Выполните `docker compose up --build`. Compose запускает PostgreSQL, применяет миграции и поднимает API. После запуска выполните `make smoke` для проверки публичных маршрутов. Swagger UI доступен по адресу `http://localhost:8080/swagger/index.html`.

## Локальный запуск фронтенда

Используйте Node.js 24. Из каталога `frontend/` выполните `npm ci` и `npm run dev`, затем откройте `http://localhost:3000/login`. Для проверок там же доступны `npm run lint`, `npm run typecheck` и `npm run build`.
